# MJl - Campaign Journal — 1.3.8

![Обложка MJl - Campaign Journal](art/campaign-journal.webp)

Персонажи, локации с галереей и общий журнал квестов для **Foundry VTT 14.361 + dnd5e 5.3.3**.

## Установка и открытие

1. Установите модуль из **MJl - Modules Hub** или вставьте адрес манифеста в штатный установщик Foundry.
   `https://raw.githubusercontent.com/MJl2517/MJl-Campaign-Journal/main/module.json`
2. Включите **MJl - Campaign Journal** в управлении модулями мира.
3. Слева откройте панель **Хроника** с иконкой книги. В ней есть **Персонажи**, **Локации** и **Квесты**. Те же окна доступны через настройки модулей.

Активный мастер может создавать и редактировать карточки самостоятельно. С **Socketlib 1.1.4+** игроки отправляют запросы сохранения активному мастеру, а второй мастер может получить ключ хранилища через защищённый канал. Без Socketlib игроки читают опубликованные записи. При потере ответа черновик остаётся в форме: обновите запись и проверьте результат перед повтором.

**Mini Calendar** отображает сроки квестов. **Pointcrawl** добавляет импорт и привязку локаций, а **Dungeon Sketch** открывает карточки и галереи по отметкам на сцене. Все эти интеграции подключаются по желанию.

Карточки персонажей, локаций и квестов открываются в **режиме просмотра**: портреты, галерея, заметки, теги, условия и ссылки без полей настройки. Кнопка **Редактировать** открывает полную форму в стиле Pointcrawl. **Сохранить** сохраняет изменения и возвращает просмотр; **Отмена** возвращает просмотр, при наличии черновика запрашивая подтверждение. Новая карточка сразу открывается для редактирования. Длинное содержимое прокручивается внутри окна; раскрытые разделы формы и прокрутка сохраняются при обновлении.

В Dungeon Sketch мастер может поставить на этаж точку, которая открывает карточку локации Хроники с её галереей. Новые карточки, созданные с карты, открываются мастеру сразу и становятся доступны игрокам после публикации.

## Персонажи

Игроки создают общие карточки НИП, меняют имя, портрет, заметки партии и теги. В редакторе теги показаны плашками: существующий тег можно найти и назначить нажатием, новый — ввести и добавить через Enter или кнопку «+». При сохранении текст из поля тега также добавляется. Регистр не создаёт дублей. Общий список тегов запоминается в настройках текущего мира и сохраняется даже после удаления тега с карточек или удаления НИП. Теги скрытых карточек мастера попадают в общий список только после раскрытия карточки. На листе показаны только назначенные теги и до восьми подходящих подсказок. Поле тега ищет по всей библиотеке, даже если меток сотни. **Все теги** в редакторе или **Теги** в шапке каталога открывает отдельное окно с поиском и страницами по 25 записей. Там можно назначить тег редактируемому НИП или удалить общий тег корзиной. Карточка игрока сразу открыта партии. Карточка мастера сначала закрыта: флажок **Открыта игрокам** управляет доступом.

Крестик на плашке снимает тег только с текущего НИП после сохранения. Корзина в общем списке с подтверждением удаляет тег из библиотеки и всех открытых карточек НИП, включая архив; скрытые карточки мастера не меняются. Операция проходит через подключённого мастера. Если использования тега изменились во время подтверждения, удаление отклоняется до начала изменений. Текущий черновик инициатора сохраняется; устаревшие черновики других авторов получают обычный конфликт при сохранении. При новом назначении тег можно создать снова.

В редакторе НИП откройте **Текущая локация → Выбрать локацию**. Мастер может выбрать любую неархивную локацию Хроники, включая места, ещё не раскрытые в Pointcrawl. Игроки могут выбрать только доступные им карточки. Пока назначенное место скрыто, в карточке персонажа игроки видят **Неизвестно**. Когда место становится доступно, появляется ссылка на его карточку. Обычные правки персонажа сохраняют назначенное место. Чтобы убрать связь, выберите **Не указана**.

**Заметки мастера** и привязанный статблок доступны только мастеру. Для статблока перетащите Actor из каталога мира или компендиума в соответствующее поле; кнопка откроет его штатный лист. Мастер может перетащить портрет НИП в просмотре или кнопку **Статблок** на сцену: штатный обработчик Foundry создаст токен. Для Actor из компендиума Foundry при этом импортирует его в мир. Обычный клик по кнопке продолжает открывать лист. Строка НИП в каталоге переносит карточку журнала для связей квеста.

В карточке сохраняется ссылка на исходный Actor; его разрешения не меняются. При удалении Actor карточка сохраняется.

Поиск учитывает имя, заметки и теги без учёта регистра; мастер также ищет в секретных заметках. Выбранный тег дополнительно ограничивает список.

## Арты и локации

Локации создаёт мастер. У открытой игрокам карточки видны **все изображения галереи с подписями**, доступно увеличение нажатием. Игроки редактируют общие заметки; изображения добавляет и меняет мастер. Секретные заметки мастера не раскрываются. У закрытой локации игрокам не передаются название, заметки и галерея.

Для портрета НИП или арта локации:

- **Выбрать арт** открывает стандартный FilePicker Foundry.
- Перетащите файл изображения или путь / ссылку в область арта.
- Для вставки изображения или ссылки нажмите на область арта и затем **Ctrl+V**. Внутри текстового поля обычная вставка текста сохраняется.
- Нажатие изображения открывает штатный увеличенный просмотр. **Убрать из галереи** убирает ссылку, сохраняя файл на диске.

Загрузка файлов использует штатные права Foundry **Загрузка файлов** и **Просмотр файлов**; модуль сам их не расширяет. Файлы помещаются в `worlds/<world-id>/mjl-campaign-journal/`. Без права загрузки можно выбрать арт, уже сохранённый внутри текущего мира; перенос нового изображения извне требует этого права. Несохранённый арт не заменяет прежний при ошибке загрузки.

При включённом Pointcrawl мастер может нажать **Выбрать локацию Pointcrawl** в режиме редактирования карточки. В поиске доступны открытые и скрытые места по их названиям. Скрытые помечены **Скрыто от игроков**. Общие заметки после связывания ведутся в исходном журнале через кнопку его открытия. Перед связыванием перенесите прежние заметки в этот журнал и сохраните карточку с пустыми общими заметками. Игроки увидят связанную карточку, когда и она, и место в Pointcrawl открыты для партии.

В окне привязки нажмите на название региона, чтобы развернуть его подлокации. Строка **Весь регион** связывает карточку с журналом региона. Поиск автоматически раскрывает подходящие группы.

Чтобы добавить сразу все места, откройте **Локации → Импорт из Pointcrawl**, выберите сцену и нажмите **Импортировать**. Хроника создаст карточки регионов и подлокаций по действующим журналам сцены. Уже привязанные места пропускаются. Новые карточки скрыты до публикации мастером. В каталоге регионы и подлокации отсортированы по названиям, а подлокации вложены в карточку своего региона, если она доступна пользователю.

Для самостоятельных локаций мастер может создать свою иерархию. В каталоге перетащите строку будущей подлокации на другую самостоятельную локацию. Нажмите на заголовок родителя, чтобы свернуть или развернуть ветку. Для отмены вложения щёлкните правой кнопкой по подлокации и выберите **На верхний уровень**. Видимость настраивается для каждой карточки отдельно. Перед привязкой такой карточки к Pointcrawl вынесите её и её непосредственные подлокации на верхний уровень.

При использовании Pointcrawl 1.0.22 или новее первое изображение галереи связанной карточки открывается также из чата Pointcrawl после прибытия. Замена через менеджер Pointcrawl обновляет первое изображение и сохраняет остальные арты, подписи и настройки видимости карточки.

## Квесты и сроки

В списке квестов есть фильтры **Все квесты**, **Активные**, **Просроченные**, **Завершённые**, **Проваленные**. Активные включают все незавершённые квесты, в том числе просроченные; отдельный фильтр просроченных показывает только активные с истекшим сроком. Поиск и просмотр архива работают вместе с выбранным фильтром. Перевод игрового времени пересчитывает просрочку, не сбрасывая черновик.

Квесты общие для партии. В просмотре показываются описание, условия, срок, заметки и ссылки в компактных блоках. Если у активного квеста есть условия и все отмечены, появляется **Завершить квест**. Нажатие сохраняет статус **Выполнен** и убирает событие срока из Mini Calendar. Одни чекбоксы по-прежнему не меняют статус автоматически. Чекбоксы условий можно отмечать и снимать прямо здесь: изменение сразу сохраняется через мастера и обновляется у партии. Без подключённого мастера чекбоксы недоступны. Через **Редактировать** любой игрок задаёт название, описание, условия с чекбоксами, заметки и связи. **Добавить персонажа** и **Добавить локацию** открывают отдельные окна выбора с поиском; локации предлагаются только открытые и неархивные. Перетаскивание карточек из списка Хроники также работает в редактировании. Закрытая или удалённая цель ссылки показывается как **Запись недоступна**.

Статусы **Активен**, **Выполнен**, **Провален** назначаются вручную. Отметки условий не меняют статус автоматически. Записи можно помещать в архив и возвращать. ПКМ по строке записи в списке или свободной области карточки просмотра любого типа открывает контекстное меню (кнопки, ссылки, арты, чекбоксы и поля его не вызывают; на форме редактирования меню нет): **В архив**, в архиве — **Вернуть из архива**. У мастера есть **Удалить навсегда** с подтверждением; активная карточка перед удалением автоматически архивируется. Отмена подтверждения не архивирует запись. Файлы артов и Actor при этом сохраняются.

В ограничении времени выберите:

- **Оставить текущий срок** — обычные правки не меняют установленную дату.
- **Без срока** — убрать ограничение.
- **Дата и время календаря** — точная дата используемого игрового календаря.
- **Через N дней / часов** — отсчёт от текущего игрового времени при сохранении, затем фиксированная дата. Для нового отсчёта выберите этот вариант снова.

Учитываются длина суток, часов и минут календаря мира. Остаток обновляется при изменении игрового времени, включая отдых и путешествия. Модуль не переводит время сам. При достижении срока активный квест получает отметку **Просрочен**; партия уведомляется один раз для этой даты. Автоматического провала нет. Перевод времени назад пересчитывает остаток; повторное пересечение той же даты не создаёт нового уведомления.

В Mini Calendar появляется видимое игрокам событие **Срок: название квеста** с точным временем и ссылкой на журнал квеста. В заголовке журнала есть кнопка **Хроника · открыть карточку**. Изменяйте срок в Хронике: при синхронизации карточка имеет приоритет над ручной правкой события календаря.

Перенос срока переносит событие. Завершение, провал, архивирование или снятие срока убирают его; возврат в активные восстанавливает. При сбое сохраняется сам квест и показывается ошибка календаря. Мастер может нажать **Синхронизировать календарь**; повтор также происходит при подключении мастера. Без Mini Calendar работают записи и отсчёт. Его исходники не изменяются; адаптер проверяет наличие используемого интерфейса и сообщает о несовместимости.

Если Mini Calendar отключён, для окончательного удаления квеста с ещё существующим событием сначала включите календарь. Это предотвращает появление события без квеста; архивирование и правки записей остаются доступны.

В меню ПКМ квестов можно выбрать **Статус: Активен / Выполнен / Провален**. Изменение доступно игрокам для открытых квестов. Если у выбранной карточки есть черновик, предлагается отменить его перед сменой статуса; действия над другой карточкой не стирают текущий текст.

Мастеру в меню всех трёх типов доступны **Открыть игрокам** и **Скрыть от игроков**. Игрокам эти пункты не показываются; подменённые запросы отвергаются мастером. Скрытие активного квеста убирает событие срока, раскрытие восстанавливает его. У выполненных и проваленных квестов события срока отсутствуют.

## Данные и арты текущего мира

Все записи относятся к текущему миру: общие карточки — его JournalEntry, секретное хранилище — его компендиум `world.mjl-campaign-journal-private` в папке `worlds/<id мира>/packs/`. Мировой список тегов также изолирован от других миров.

Загруженные файлы сохраняются в `worlds/<id мира>/mjl-campaign-journal/`. Арты, выбранные из других папок Foundry или вставленные ссылкой, мастер при сохранении копирует в `worlds/<id мира>/mjl-campaign-journal/art/`; одинаковое содержимое использует один файл. Ссылки внутри текущего мира остаются на месте. Исходные файлы не удаляются. Файловые права игроков и обычная загрузка Foundry сохраняются.

При подключении мастера арты старых карточек автоматически переносятся таким же способом. Исходные пути сохраняются в зашифрованной записи мастера. Если источник недоступен или внешний сервер запрещает загрузку из браузера, старый путь остаётся, а мастер видит предупреждение. Можно загрузить изображение файлом и сохранить карточку снова. Ошибка нового арта не меняет ранее сохранённую карточку; недоступный старый арт не мешает заметкам или архивированию. Ссылки на Actor и исходные журналы Pointcrawl продолжают вести к исходным документам.

## Секретное хранилище и резервная копия

Общие карточки находятся в папках журналов **Хроника · Персонажи / Локации / Квесты**. Игрокам выдан просмотр; редактирование через интерфейс Хроники выполняет подключённый мастер. При одновременных правках одной карточки устаревшее сохранение отклоняется, текст второго автора остаётся в форме.

Секретные данные находятся в компендиуме **Хроника · секреты мастера**, зашифрованные AES-GCM. Это также защищает содержимое от прямого запроса документов компендиума игроком в Foundry 14.361. В общую карточку открытой локации входят арты с подписями. Секретные заметки, UUID статблоков и резервные ссылки на исходные изображения в общие карточки не входят.

Браузер мастера должен открывать Foundry через **localhost или HTTPS**, чтобы был доступен штатный WebCrypto. Ключ предназначен для личного профиля браузера мастера.

**После первого запуска сохраните ключ:** Настройки → Настройки модулей → **MJl - Campaign Journal · ключ мастера** → **Скачать резервный ключ**. Храните его отдельно от игроков вместе с резервной копией мира. Сам ключ сохраняется только в браузере мастера; резервная копия мира его не содержит. Потеря ключа во всех браузерах делает секреты невосстановимыми. В новом браузере импортируйте файл через это же окно и перезагрузите страницу. При включённом Socketlib второй мастер может получить ключ от активного мастера; передача зашифрована для получателя и проверяет его роль.

Отключение модуля не удаляет журналы, файлы изображений или компендиум. Секреты будут доступны после повторного включения с сохранённым ключом. Модуль не изменяет ядро, систему, исходники других модулей и базы кампании напрямую.

Выпадающие списки используют системные цвета Canvas / CanvasText и цветовую схему Windows. Текст пунктов остаётся читаемым при светлой и тёмной системной схеме независимо от темы окна Foundry.

## API и проверки

```js
const api = game.modules.get("mjl-campaign-journal").api;
api.version; // 1
api.openNPCs();
api.openLocations();
api.openQuests();
api.openEntry("JournalEntry.<id>");
```

Для связи с Dungeon Sketch служат `mapLocations()`, `prepareMapLocation({id, name})` и `openMapLocation(id)`. Список и открытие учитывают доступ текущего пользователя, а подготовку точки выполняет мастер.

Из папки исходников запустите `npm test`, чтобы проверить правила, разграничение доступа и перенос артов. Сценарии Foundry запускаются в отдельном тестовом мире. Результаты и границы проверки описаны в `VALIDATION.md`.
